## 1. 弹窗与启动链路（R1）

- [ ] 策略确认弹窗、平仓确认弹窗、负债说明弹窗均挂载在 `document.body`（元素检查：弹窗不是 `.strategy-layout`/滚动容器的后代）。
- [ ] 弹窗蒙层上**起手滑动/拖动**不会关闭弹窗；**原地静止点按**蒙层才关闭。
- [ ] 弹窗内滚动列表时页面背景不滚动（body 锁定）。
- [ ] 确认按钮快速连点两次：只产生一次下单请求（策略列表/订单列表只出现一条）。
- [ ] 提交中按钮显示 Submitting…/Applying…，结束后恢复。
- [ ] 启动按钮被禁用时旁边显示原因文案（行情未就绪 / 报价未对齐 / 保证金不足），不再是纯灰色无解释。
- [ ] 软键盘弹出再收起后，弹窗仍在视口内、按钮仍可点中（dvh 近全屏布局）。

## 2. 对账平仓（R2/R3）

- [ ] 持仓合并列表 → Close position：弹窗出现「Reconciling quantities with the exchange…」，随后数量按交易所真值刷新。
- [ ] 快照与交易所不一致（先在交易所手动减仓再打开弹窗）：提交数量为交易所数量，不出现残量。
- [ ] 平仓完成后若仍有残量：出现残量弹窗（符号/数量/原因/建议），文案含"不会自动强平碎量"。
- [ ] carry 策略行 → Close all：双腿 closePlan 策略启动；任一腿数量被交易所拒绝时另一腿不受影响，策略最终 COMPLETED。
- [ ] 全部平掉后策略行收敛为已完成，无残留僵尸行。

## 3. 报价对齐（R4）

- [ ] 策略页两腿 dl 各显示一行 Quoted at 时间；价差数字在两腿时间差 >2s 时显示「—」并标注 Leg quotes are not time-aligned。
- [ ] 价差质量榜底部组合出现「Quotes misaligned」徽标时该组合位于列表末尾。
- [ ] （可选）设置 `GCT_SPREAD_SKEW_MS=500` 重启后端：更多组合被标注未对齐。

## 4. 列表合并与导航（R6/R7/R9）

- [ ] 交易页底部只有两个 tab：Positions / Orders，徽标数 = 合约+现货之和。
- [ ] Positions 列表合约与现货同表、每行带 Perp/Spot 标签、按价值降序；chips All/Perpetual/Spot 可筛。
- [ ] Orders 视图 chips（Open orders / Order history / Trade history）与市场类型 chips 均可筛；合约挂单在合并视图可撤单。
- [ ] 旧版本持久化的 tab key（futures-positions / spot-trade-history / "Order history" 等）恢复会话后不白屏，落在合并 tab 上。
- [ ] 顶部导航 6 入口：交易 / 策略▾ / 机会▾ / 资金费率 / 资产 / 更多▾；机会▾ 4 个子榜全部可达；更多▾ 含 Boros 与交易手续费。
- [ ] 资产页一级入口直达 Portfolio。

## 5. 价差质量榜排序分页（R8）

- [ ] 排序 chips 六项可点，激活项显示方向箭头，再次点击翻转方向；列表顺序随之变化且不触发整榜重算（网络面板只发一次带 sort/dir 的请求）。
- [ ] 分页 20/50 可切换，翻页覆盖全部候选（页码范围与 total 一致）。
- [ ] 30s 内来回切换页面：机会榜不白屏（stale-first），后台自动刷新。

## 6. 视口与触控（R10）

- [ ] 顶栏导航按钮、底部 tab、表格操作按钮触控热区 ≥44×44px。
- [ ] 图标（含 Boros 标志）无裁切、无换行挤压。
- [ ] 横屏/竖屏切换后弹窗仍居中可滚动，无页面级横向滚动条。
- [ ] 表格窄屏横向滑动流畅，有滚动余量（table-wrap）。
